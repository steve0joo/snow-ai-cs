# User Journey & Use Case 카탈로그 (taxonomy v0 근거)

> **스코프 주의**: 이번 분석 대상은 **SNOW + B612**(구글플레이)다. 101cam은 안드로이드 미출시(2026-09 확인)로 제외되었으나, 신규 앱의 "지연 피드백" 시나리오는 분류 체계 설계에 유용한 **참고 사례**로 아래에 보존한다.
>
> 이 문서는 **가설**이다. 여기서 도출한 분류 체계(`taxonomy.json`, v0)는 정답이 아니라 파일럿 수동 태깅에서 **검증·파괴될 대상**이다. 한 번은 깨지는 것이 정상이며, 그 v1→v2 재설계 과정 자체가 이 프로젝트의 핵심 산출물이다.

## A. User Journey Map — 카메라/AI 앱 유저는 어떻게 쓰는가

| # | Journey 단계 | 유저 목표 | 대표 마찰·실패 지점 |
|---|---|---|---|
| 0 | 인지·설치 | 발견→다운로드→첫 실행 | 기기 미지원, 용량 부족, 실행 즉시 크래시 |
| 1 | 온보딩·권한·계정 | 권한 허용, 로그인/가입 | 권한 거부 후 먹통, 소셜 로그인 실패, 기기 이전 실패 |
| 2 | 기능 탐색 | 원하는 필터/기능 찾기 | "그 기능 어디 있어요?", 유·무료 경계 불명확 |
| 3 | 입력·촬영 | 촬영 or 사진 업로드 | 실시간 촬영 지연, 업로드 실패, 형식/화질 조건 |
| 4 | **AI 생성** ★ | 스타일 선택→결제→대기→결과 | 무한 대기, 생성 실패, 크레딧만 소모 |
| 5 | **결과 확인·재생성** ★ | 결과 확인, 재시도 | "나를 안 닮았다", 왜곡/부적절, 재생성 추가 과금 |
| 6 | 저장·내보내기 | 결과물 기기 저장 | 화질 저하, 워터마크, 저장 실패 |
| 7 | 공유 | SNS/링크 공유 | 공유 실패, 원치 않는 노출 |
| 8 | **결제·구독** ★ | 개별 결제 / VIP 구독 | 중복결제, 자동갱신 미인지, 환불 요구, 해지 방법 |
| 9 | 사후·유지 | 재방문, 해지, 탈퇴 | 구독 해지 안 됨, 계정/데이터 삭제, 광고 과다 |

★ = 문의량·판정 난이도가 동시에 높은 결정 구간.

## B. 결정적 통찰 (분류 체계를 좌우)

1. **AI 생성 앱은 "결제가 결과보다 먼저" 일어난다.** 돈을 낸 뒤 결과가 나오므로 "냈는데 결과가 안 나옴/맘에 안 듦"은 버그가 아니라 결제-생성 순서가 만드는 구조적 클레임. → 유형 3(AI생성)과 5(결제)가 한 리뷰에 엉키는 근본 원인.
2. **"취향 불만"은 판정 불가 → 챗봇이 절대 못 푸는 C등급의 핵심.** "얼굴이 안 닮았다"는 불량이 아니라 취향인데 돈을 냈다. 챗봇에 넘기면 안 되는 대표 유형이자 "사람 필수 비율"의 근거.
3. **앱 간 분포 차이 관찰** — SNOW와 B612는 자매 앱이지만 사용 결이 다르다(SNOW=AI 아바타/프로필 결제 비중↑, B612=일상 카메라/편집 비중↑). "같은 회사 앱인데 문의 유형 분포가 어떻게 다른가"가 이번 스코프의 관찰 포인트.
4. **[참고, 스코프 밖] 101cam의 "지연된 피드백 루프".** 뷰파인더에 필터 미적용 → 셔터 후 결과 확인. "화면이랑 결과가 달라요"는 **정답이 고정된 A등급** 문의(FAQ 1건으로 완결). 신규 앱의 온보딩 문의가 A등급으로 몰리는 사례로, 안드로이드 출시 시 재검토할 가치가 있다.

**미리 보이는 지뢰 (파일럿에서 터질 것):**
- `3+5` 복합 유형이 여러 건 → 원본이 예언한 "AI 결과물 불만 ↔ 환불이 한 리뷰에 온다". **주 유형 + 부 유형** 규칙으로 흡수.
- 같은 유형 3인데 등급이 A/B/C로 다 갈림(재생성 과금=A, 무한대기=B, 취향불만=C) → **유형(What)과 등급(So what)은 반드시 별도 축**이어야 함을 실증.

## D. 파이프라인 연결

- **preprocess/tag**: 위 카탈로그의 대표 시나리오 = LLM 태깅 few-shot 예시.
- **검수(analyze 전)**: 무작위 검수 + "journey 10단계가 다 커버됐나" 커버리지 체크.
- **리포트**: (1) "가설(v0) vs 실측" 비교 섹션, (2) **SNOW vs B612 유형 분포 차이** 섹션을 넣는다 → 최상위 면접 소재.
