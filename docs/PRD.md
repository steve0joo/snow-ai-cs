# PRD: SNOW VOC 미니 프로젝트

## 목표
SNOW·B612의 공개 앱 리뷰를 수집·분류해, "CS 문의 유형 분포"와 "챗봇 자동화 가능 비율(추정)"을 도출하고 A4 리포트 1장으로 제시한다.

## 배경
SNOW "AI CS 기획/운영 인턴"(직군: Service & Business > Product Development) 지원용. 이 자리의 실제 요구는 **문의 분류 체계(taxonomy) 설계 + AI 답변 품질 관리**이며, 지원자가 합법적으로 접근 가능한 공개 VOC(스토어 리뷰)로 그 역량을 사전 증명하는 것이 목표다.

## 사용자
- 1차: 지원자 본인(파이프라인 실행자)
- 산출물 독자: SNOW 채용 담당/면접관

## 핵심 기능 (파이프라인 4단계)
1. **수집** — 구글플레이 리뷰 수집 (SNOW, B612 / 한국어), 별점 층화
2. **전처리** — 중복·결측·PII 처리, 스키마 정규화, 약 500건 샘플 확정
3. **태깅** — taxonomy(2축 + 플래그)로 분류. LLM 1차 + 무작위 수동 검수
4. **분석·리포트** — 유형 × 챗봇등급 크로스탭, 자동화 가능 비율, 가설 vs 실측, 앱 간(SNOW vs B612) 분포 차이, 한계

## 스코프
- 대상 앱: SNOW(`com.campmobile.snow`), B612(`com.linecorp.b612.android`) — 둘 다 SNOW Corporation
- 스토어: 구글플레이만
- 언어: 한국어
- 표본: 약 500건 (앱당 ~250), 검수 무작위 ~50건

## MVP 제외 사항
- **101cam** — iOS 전용(안드로이드 미출시, 2026-09 확인). 구글플레이 스코프에서 수집 불가 → 제외 (docs/ADR.md ADR-001)
- App Store / 다국어(일본어 등) 리뷰
- 나머지 앱(SODA, Foodie)
- 실시간·반복 수집, 대시보드, DB
- 정교한 봇 탐지·언어 감지·재시도 백오프 (docs/ADR.md ADR-007)

## 성공 기준
1. 재현 가능한 4단계 스크립트가 에러 없이 실행됨
2. 유형 × 챗봇등급 크로스탭 표 1개 생성
3. LLM 태깅 vs 수동 검수 일치율 산출
4. 한계 4가지가 명시된 리포트 1장 완성

## 방법론적 전제 (면접 방어선)
- 리뷰는 CS 문의의 **대리 지표(proxy)**. 결제·환불 유형은 실제보다 과소 추정될 수 있음.
- "자동화 가능 비율"은 **추정치**이지 실제 문의 인입 감소율이 아님.
- taxonomy는 user journey 기반 **가설(v0)**이며, 파일럿 태깅에서 검증·수정되어 v1이 된다. (docs/USER_JOURNEY.md)
