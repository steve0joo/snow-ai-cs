# SNOW·B612 앱 리뷰 VOC 유형 분석 리포트

> 표본 495건(태깅 완료, 검수큐 5건 제외) · 기간 2021-11~2026-09 · 구글플레이 한국어 · SNOW 250 / B612 250

## 1. 요약 (3줄)

- 실질 문의(유형 1~7) 400건 중 최다 유형은 **촬영·기능 사용**(35.4%)이며, 무내용(0번)은 전체 태깅의 19.2%다.
- 챗봇 **완전 자동(A등급) 후보는 문의의 38.8%**, 백엔드 연동을 포함한 A+B는 66.0%다 — **자동화 가능 비율은 추정치이지 실제 인입 감소율이 아니다.**
- SNOW와 B612는 자매 앱이지만 유형 분포가 갈린다(3항 참조), 앱을 고쳐야 하는 신호(product_issue=Y)가 254건 잡혔다.

## 2. 방법 (표본·기간·태깅·검수)

- **표본**: 구글플레이 한국어 리뷰 495건(앱당 ~250, 별점 층화). 무작위가 아니라 별점 층화 추출이라 모집단을 그대로 대표하지 않는다(ADR-005).
- **기간**: 2021-11 ~ 2026-09 (리뷰 작성월 기준).
- **태깅**: taxonomy(2축+플래그, `taxonomy.json`)로 LLM 1차 배치 태깅(temperature=0). 파싱 실패·범위 밖은 검수큐(null)로 두었고 이번 표본에서 5건이다.

- **검수**: `data/processed/human_audit.csv`(무작위 ~50건)를 넣으면 `review_id` 조인으로 LLM vs 수동 일치율이 자동 산출된다(현재 미수행, 훅 준비됨).

| 유형 | A 건수 | 유형 내 A 비중 |

## 8. 한계 (4가지)

1. **리뷰는 CS 문의의 대리 지표(proxy)다.** 결제·환불처럼 고객센터로 직행하는 문의는 리뷰에 덜 남아 실제보다 과소 추정될 수 있다.
2. **한국어·구글플레이·2개 앱(SNOW, B612)에 편중**됐다. App Store와 해외(약 40% 시장) 유형 분포는 검증하지 못했다.
3. **A등급 비율은 자동화 '가능성 추정치'이지 실제 문의 인입 감소율이 아니다.** 내부 티켓 데이터 없이 인입 감소율은 산출할 수 없다.
4. **LLM 1차 태깅의 불일치는 경계 유형(취향 불만 vs 품질 불량, AI생성↔결제 복합)에 집중**된다. 이 경계가 곧 taxonomy를 v1로 고쳐야 할 지점이다.
